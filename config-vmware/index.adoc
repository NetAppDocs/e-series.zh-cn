= E 系列 VMware 主机配置快速入门
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
用于安装存储阵列和访问 SANtricity System Manager 的 VMware 快速方法适用于为配备 E 系列存储系统的独立 VMware 主机进行设置。它旨在以最少的决策点使存储系统尽快启动并运行。



[[procedure-overview]]
== 操作步骤概述

此快速方法包括以下步骤，也在中进行了概述 link:understand-vmware-workflow-concept.html["VMware 工作流"]。

. 设置以下通信环境之一：
+
** link:nvme-fc-perform-specific-task.html["基于光纤通道的 NVMe"]
** link:fc-perform-specific-task.html["Fibre Channel（光纤通道）(FCP)"]
** link:iscsi-perform-specific-task.html["iSCSI"]
** link:sas-perform-specific-task.html["（ SAS ）。"]
** link:nvme-roce-perform-specific-task.html["基于 RoCE 的 NVMe"]
** link:nvme-tcp-perform-specific-task.html["基于 TCP 的 NVMe"]


. 在存储阵列上创建逻辑卷。
. 使卷可供数据主机使用。
