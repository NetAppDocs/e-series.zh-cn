= 在 E 系列 Linux NVMe over TCP 主机上设置故障转移
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要为存储阵列提供冗余路径，您可以将主机配置为运行故障转移。

.开始之前
请参阅 https://mysupport.netapp.com/matrix["NetApp 互操作性表工具"^]以确保安装了任何所需的更新，因为初始版本中不可用的 SLES 或 RHEL 版本可能需要重要的错误修复。

.关于此任务
对于 SLES 15、SLES 16、RHEL 9 和 RHEL 10，默认情况下启用原生 NVMe 多路径，无需额外配置。



[[configure-nvme-io-policy]]
== 配置 NVMe I/O 策略

.关于此任务
Linux NVMe 本机多路径可能默认为 `numa` I/O 策略。对于 E 系列/EF 系列 NVMe-over-Fabrics 配置，建议的 I/O 策略是 `round-robin`，它在所有可用路径上均匀分配 I/O。

.步骤
. 验证当前 NVMe I/O 策略：
+
[listing]
----
# cat /sys/module/nvme_core/parameters/iopolicy
numa
----
. 使用以下方法之一设置 `round-robin` I/O 策略：
+
** *持久（推荐）* — 创建 udev 规则文件：
+
.<code>/etc/udev/rules.d/71-nvme-io-policy.rules</code>
[listing]
----
ACTION=="add|change", SUBSYSTEM=="nvme-subsystem", ATTR{iopolicy}="round-robin"
----
+
然后重新加载并应用规则：

+
[listing]
----
udevadm control --reload
udevadm trigger --subsystem-match=nvme-subsystem
----
** *引导时的全局设置* — 将以下内核参数添加到引导加载程序配置中：
+
[listing]
----
nvme_core.iopolicy=round-robin
----
** *非持久性（在线，无 I/O 中断）* — 立即应用，无需重新启动：
+
[listing]
----
echo "round-robin" > /sys/class/nvme-subsystem/nvme-subsys0/iopolicy
----
+

NOTE: 此设置在重启后不会保留。
